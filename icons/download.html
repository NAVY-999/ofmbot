Pack M1 Profondeur

Télécharger les icônes

Un bouton par icône. Le fichier part dans Téléchargements, et X Icon Changer ira le chercher là ou dans ta Galerie.

Normal

Dans la Galerie Samsung, les coins arrondis apparaissent blancs. C'est juste la façon dont la Galerie affiche la transparence — le fichier est bon, et l'icône sera bien détourée une fois posée.

Étape suivante

Poser une icône avec X Icon Changer

Commence par une seule, CIC par exemple. Si le résultat te plaît, fais les autres.

  1. Ouvrir X Icon Changer : la liste de tes applications s'affiche.
  2. Appuyer sur CIC dans la liste.
  3. Un écran s'ouvre avec l'icône actuelle à gauche et le nom à droite. Appuyer sur l'icône — c'est elle le bouton, pas le nom.
  4. Choisir Photos ou Galerie, puis Téléchargements, et sélectionner cic.png.
  5. Si un recadrage s'affiche, ne rien changer : valider tel quel.
  6. Appuyer sur OK puis Enregistrer. Android propose d'ajouter à l'écran d'accueil : accepter.
  7. Appui long sur l'ancienne icône → Retirer. Ça enlève le raccourci, ça ne désinstalle rien.

Si le bouton ne déclenche rien, appui long sur la vignette de l'icône ci-dessus, puis Télécharger l'image.
