Installation

Comment poser les icônes

Je ne peux pas le faire à ta place : je n'ai aucun accès à ton téléphone. Voilà les deux chemins possibles — celui que tu prends dépend d'une seule chose, ton launcher.

Clé

Ni le Pixel Launcher ni One UI Home (Samsung) ne permettent de remplacer l'icône d'une app. C'est une limite du launcher, pas d'Android. Les thèmes Samsung n'appliquent que des packs complets, jamais une image que tu choisis. Donc : soit tu changes de launcher (méthode A), soit tu passes par des raccourcis (méthode B).

Méthode A — recommandée

Changer de launcher

Pour Nova Launcher, Lawnchair ou Niagara. L'icône est vraiment remplacée, proprement, sans badge ni doublon.

  1. Installer le launcher depuis le Play Store, l'ouvrir une fois, puis le définir comme application d'accueil par défaut quand Android le propose.
  2. Copier les cinq PNG sur le téléphone — le dossier Téléchargements convient, il suffit qu'ils soient visibles par la galerie.
  3. Appui long sur l'app sur l'écran d'accueil → Modifier (Nova) ou Edit (Lawnchair).
  4. Toucher l'icône affichée dans la fenêtre qui s'ouvre — c'est elle le bouton, pas le nom de l'app.
  5. Choisir Images ou Galerie dans la liste des sources, puis sélectionner le PNG.
  6. Valider. Répéter pour les quatre autres.

Ce que ça coûte : changer de launcher remplace tout ton écran d'accueil. Tu devras reposer tes widgets et réorganiser tes pages une fois. Après ça, plus rien à refaire.

Méthode B — sans rien changer

Passer par des raccourcis

Pour garder ton launcher actuel. Une app tierce crée un raccourci qui porte la nouvelle icône et ouvre l'app d'origine.

  1. Installer X Icon Changer ou Shortcut Maker depuis le Play Store.
  2. Ouvrir l'app, choisir CIC dans la liste des applications installées.
  3. Toucher l'icône, choisir Galerie / Photos, sélectionner le PNG.
  4. Valider : le raccourci se pose sur l'écran d'accueil avec la nouvelle icône.
  5. Retirer l'ancienne icône de l'écran d'accueil — l'app reste dans le tiroir, tu ne désinstalles rien.

Ce que ça coûte : c'est un raccourci, pas l'app. Certains launchers ajoutent une petite flèche dans un coin, et la pastille de notification ne suit pas toujours. Pour CIC et PayPal, l'app s'ouvre normalement.

Livraison

Les fichiers

Le masque squircle est déjà appliqué et les coins sont transparents — rien à recadrer. Une précision : les marques CIC sont plus larges que le cercle de 72 dp, parce qu'un « C I C » horizontal réduit à ce cercle deviendrait minuscule. Elles restent largement dans le squircle, donc rien n'est coupé — mais si tu passes un jour à un launcher qui masque en cercle, ces deux-là sont à refaire. Les trois autres tiennent dans le cercle.
